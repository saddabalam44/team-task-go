# TeamTaskGo — Frontend Application

React 19 + Vite frontend built with Tailwind CSS v4 and Framer Motion for TeamTaskGo task manager.

## ⚙️ Setup & Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Environment Variables:
   Configure `.env` using `.env.example` as a guide:
   ```env
   VITE_API_URL=/api
   ```

3. Run Development Server:
   ```bash
   npm run dev
   ```

4. Build for Production:
   ```bash
   npm run build
   ```
